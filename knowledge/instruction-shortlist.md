# Swing instruction shortlist

## Project filtering rule

This shortlist is intentionally small and only includes swing-instruction sources that directly relate to:

- over-the-top motion
- sequencing and weight shift
- a freer, more natural swing
- 7-iron quality and distance
- transfer to the driver without forcing the action

Anything focused on short game, bunker play, or putting is excluded from this list unless it clearly affects the core swing pattern.

## Ranked shortlist

### 1) Danny Maude
Type: Practical online coach
Why keep: clear, repeatable language around swing faults, tempo, and sequencing; good reference for how to explain swing issues simply.
Best use: compare his sequencing cues against your own video and shot pattern.
Project fit: high

### 2) MyGolfSpy / over-the-top drill references
Type: Drill-based instruction
Why keep: the headcover drill and outside-the-ball obstacle concept is directly relevant to the over-the-top issue and path awareness.
Best use: use as a feedback drill, not as a full swing prescription.
Project fit: high

### 3) TrackMan club path references
Type: Data / technical reference
Why keep: excellent for understanding how path, face, and strike affect distance and inaccuracy; helps connect the swing fix to measurable ball flight.
Best use: use as a measurement reference when reviewing the actual swing.
Project fit: high

### 4) Broad swing-sequencing references from repeatable instructors
Type: Comparison set
Why keep: useful as a comparison library to test whether a cue improves sequence and pressure shift in your actual motion.
Best use: score each one against the instruction scorecard before adopting it.
Project fit: medium

### 5) Non-swing content
Type: general golf content
Why keep: not a project priority.
Best use: none for this phase.
Project fit: low / exclude

## Keep / test / discard rule

### Keep
Keep a source if it does all of the following:

- directly improves sequencing or reduces over-the-top motion
- helps pressure shift and body turn
- increases contact quality without tension
- produces measurable improvements in 7-iron strike or distance

### Test
Test a source if it has a useful cue but is not yet proven.

- use it for one to three practice sessions
- score it against the instruction rubric
- compare before and after video or data

### Discard
Discard a source if it:

- does not help with your actual swing pattern
- creates more complexity than value
- changes the swing but worsens contact or distance
- focuses on short-game or non-swing details

## Weekly decision process

1. Pick one or two swing cues from this shortlist.
2. Apply them to half-speed or focused reps.
3. Review video and shot quality.
4. Score the source using the instruction scorecard.
5. Keep only the winners.
