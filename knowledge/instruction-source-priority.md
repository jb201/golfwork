# Instruction source priority: swing first

## Purpose

This project is not trying to optimize short game, bunker play, or putting. The current focus is the swing itself: over-the-top motion, sequencing, weight shift, and creating a freer, more natural path.

## Filter for any online instruction

Only keep a source if it helps answer one of these questions:

- Does it improve sequencing from lower body to torso to arms?
- Does it reduce the feeling of coming over the top?
- Does it encourage pressure shift and a stronger weight transfer?
- Does it help the swing feel more natural instead of forced?
- Does it make the 7-iron and driver pattern more repeatable?

If an instruction does not map to the swing pattern, it should not be a project priority.

## Danny Maude as a reference

Danny Maude is worth including as a reference because his instruction tends to be practical, highly visual, and oriented around common swing problems like poor sequencing, club path, and timing. He is not the final authority for this project, but he is a useful benchmark for clear, repeatable swing cues.

Use him to compare against your own data and video. The right question is not 'Does this coach sound good?' but 'Did this cue improve my actual path and sequencing?'

## How to use online instruction in this project

1. Choose one coach or concept at a time.
2. Test it against a specific swing issue: over-the-top, pressure shift, or sequencing.
3. Study your own video before and after.
4. Keep only the cues that improve club path and contact without creating tension.
5. Ignore advice that creates swing complexity but no measurable change.

## Best sources to keep in Discovery later

The bookshelf should be curated for only the most useful swing-instruction sources, not a broad list of random golf content. The first pass should include high-signal swing teachers who clearly address:

- swing path and sequencing
- right-side move / pressure shift
- body turn and club delivery
- strike quality and consistency without forcing the move

Short game and putting instruction should be parked outside the main project unless they directly affect the same swing pattern.

## Current project rule

The decision rule for this phase is simple:

- Focus on the swing
- Use real stats and video
- Keep only the cues that improve repeatability and distance without adding tension
- Treat online teaching as a testing library, not a substitute for the actual data
